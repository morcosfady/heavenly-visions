# Heavenly Visions

Free phone web app (PWA) for Heavenly Visions Sunday School. Plain HTML, CSS and JavaScript, no build step.

- Live: https://morcosfady.github.io/heavenly-visions/
- Test locally: `python -m http.server 8001`, then open http://localhost:8001 in a 390 x 844 window.
- Backend tests: `node tests/backend-sim.js`
- Backend source: `apps-script/games-backend.gs` (secrets are placeholders). Firebase rules: `firebase/database.rules.json`.
