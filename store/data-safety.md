# Play Console answers: Data safety, content rating, Families

Use these when the forms ask. They match what the app really does (see `privacy.html`).

## Data safety form

**Does the app collect or share any required user data types?** Yes, collects. Shares: **No**.

| Data type | Collected | Shared | Required | Why |
|---|---|---|---|---|
| Name | Yes | No | Yes | Account, show the right class |
| Email address | Yes | No | Yes | Account sign in and the welcome email |
| User IDs (username) | Yes | No | Yes | Account |
| Phone number | Yes (servants and above only) | No | No for kids | Servants contact each other |
| App activity: in app interactions (attendance, stars, quizzes, games) | Yes | No | Yes | Rewards, attendance reports for the child's own class |
| Other user generated content (lesson plans, announcements, follow up notes, games) | Yes (servants) | No | No | App functionality |
| Location, contacts, photos, files, audio, health, financial, web browsing, device identifiers | **No** | | | |

**Is all of the user data encrypted in transit?** Yes (HTTPS only).
**Do you provide a way for users to request that data is deleted?** Yes: in the app (Profile, Delete my account) and by email (heavenlyvisions25@gmail.com). Add the privacy policy URL as the deletion web link too.
**Independent security review?** No.
**Data collected is not used for advertising, analytics or tracking.**

## Content rating (IARC questionnaire)

Category: **Reference, News, or Educational** (or "All other app types").
Violence: none (Bible stories are told gently, no graphic content). Sexual content: none. Language: none. Controlled substances: none. Gambling: none (stars are not money and cannot be bought).
User interaction: **users can not interact with each other** (no chat, no public posts). The app shares **no location**.
In app purchases: **none**. Ads: **none**.
Expected result: Everyone (ESRB), PEGI 3, USK 0.

## Target audience and Families

- Ages: 5 to 8, 9 to 12, and 13 to 17 (teens and servants also use it).
- Appeals to children: Yes. Part of **Designed for Families**.
- Ads: none. Third party SDKs: none (the Android wrapper has none).
- Permissions requested: none beyond internet.
- Teacher approved program: skip.
